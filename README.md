# Tech Diglot Digest Bot 🚀

Ежедневный дайджест ключевых новостей из мира технологий, искусственного интеллекта и гаджетов по методу двуязычного чтения (**Diglot Weave**).

## Как это работает:
1. **Поиск и агрегация:** Каждый день в полночь GitHub Actions запускает скрипт, который находит 3 ключевых события за последние 24 часа через Gemini с Google Search Grounding.
2. **Метод Diglot Weave:** В текст аккуратно вплетаются 12–15 общеупотребительных английских слов, выделенных полужирным шрифтом.
3. **Иллюстрация:** Генерируется тематическое изображение к главной новости дня.
4. **Комментарии:** Словарь для самопроверки с переводом и транскрипцией автоматически отправляется в комментарии/ответы к посту, чтобы не спойлерить чтение.

## Переменные окружения (GitHub Secrets):
* `GEMINI_API_KEY` — API-ключ Google AI Studio.
* `TELEGRAM_BOT_TOKEN` — токен Telegram-бота.
* `TELEGRAM_CHAT_ID` — ID группы в Telegram (начинается с `-100...`).
